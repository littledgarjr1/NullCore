Fonts bundled with NullCore (Geode turns each .ttf into a bitmap font at build time; see "fonts" in mod.json).

Pusab        - Geometry Dash's own font (nothing bundled).
FredokaOne   - FredokaOne.ttf is "Fredoka" (SemiBold). Fredoka One was replaced by Fredoka on Google Fonts.
Rubik        - Rubik.ttf (Medium)
Arial        - Arimo.ttf, a free look-alike with the same letter sizes. Real Arial can't be redistributed.
PressStart2P - PressStart2P.ttf
Chopin Script- DancingScript.ttf is a STAND-IN. To use the real Chopin Script, put your own
               ChopinScript.ttf in this folder and change "path" for "ChopinScript" in mod.json.
